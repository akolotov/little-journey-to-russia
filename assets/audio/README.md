# Recordings

Add your own MP3 recordings using the filenames in `src/story.js`. The story works while these files are absent. To change a sentence or filename, edit only `src/story.js`.

The seven expected recordings are:

1. `01-family-from-russia.mp3`
2. `02-flags-same-colors.mp3`
3. `03-white-blue-red.mp3`
4. `04-snowy-winter.mp3`
5. `05-blini.mp3`
6. `06-bear.mp3`
7. `07-thank-you.mp3`

Use normal browser-compatible MP3 files. The speaker button gives a readable hint if a recording is missing.
